# Gebze Pati Görselleri Rehberi

Kullanıcı tarafından sağlanan sokak hayvanları rehabilitasyon merkezi ve hayvan ambulansı görselleri bu klasöre eklenmelidir:

Klasör: `gorsel/pati/`

Önerilen dosya adlandırmaları:
1. `ambulans.jpg` - Gebze Belediyesi Hayvan Ambulansı görseli
2. `merkez_1.jpg` - Sokak Hayvanları Rehabilitasyon ve Eğitim Merkezi bina / giriş görseli
3. `merkez_2.jpg` - Tedavi ve klinik / ameliyathane alanı
4. `merkez_3.jpg` - Doğal yaşam / barınma alanı
5. `merkez_4.jpg` - Sahiplendirme / eğitim bahçesi

Uygulama otomatik olarak bu klasördeki görselleri kontrol eder; bulunamadığı durumlarda ise şık görsel yedek teması ve varsayılan belediye görselleriyle kesintisiz çalışır.
